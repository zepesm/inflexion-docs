Board KPI Hub

Add multiple KPI tiles to any monday.com dashboard — aggregations, filters, and formula columns beyond a five-value arithmetic widget.

1. Add the widget

On a dashboard, Add widget → Apps, find Board KPI Hub, and place it. Attach the boards you want to measure.

2. Create KPI tiles

  1. Click the gear icon (settings) in the widget toolbar.
  2. Choose Add KPI.
  3. Pick a board, column (Numbers, Formula, or Mirror), and an aggregation (SUM, AVG, MIN, MAX, COUNT, COUNTIF, weighted average).
  4. Optional: filters, number format (currency, %, compact like 1.0M), and a color accent.

Config is saved automatically on this widget instance via monday instance storage. You can always configure KPIs manually — AI features below are optional.

3. Plain-language KPI builder (optional, monday AI)

Describe the KPI you want in plain language. The App sends your description plus the board’s column metadata (ids, titles, types — not item values) to monday AI via monday’s run_prompt API. Review the preview carefully, then click Apply to save; nothing is saved until you apply. Usage consumes your account’s monday AI credits.

4. Explain this KPI (optional, monday AI)

Use Explain this KPI to get a short explanation of a configured tile. The App sends the KPI definition and its aggregated computed numbers to monday AI. This also uses your monday AI credits and does not change the saved configuration by itself.

5. Formula columns

Formula columns use the live API display value when available. If formula fields are rate-limited or empty, the widget falls back to a client evaluator (numbers and mirror values) and keeps the last good cache when possible.

6. Subitems (MVP)

To measure subitems, attach the subitems board to the dashboard and select that board on the KPI tile. The include-subitems toggle is not used in the MVP.

7. Status filters and “Empty”

Blank Status cells are treated as the label Empty — the same convention monday formulas use. Use that value in status filters / COUNTIF-style logic so results match board formulas.

Permissions: this app requests boards:read and ai:consume. It does not write to boards and does not store your board data (or AI prompts/responses) on an Inflexion server.

Troubleshooting

  • monday AI unavailable: AI helpers may be blocked on trial plans, when the account has no monday AI credits, or when an admin has disabled the monday AI gateway. Manual KPI configuration still works.

Tips

  • Use compact or currency formats for large totals.
  • Watch the toolbar status for Cached, Stale, or rate-limit hints.
  • Themes follow your monday account (light, dark, black).
  • Always review AI previews before Apply — AI output can be wrong.
