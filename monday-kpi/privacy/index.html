Summary

This app is a frontend-only dashboard widget. It runs inside monday.com, reads board data with the boards:read scope, optionally uses monday AI via ai:consume, and stores widget configuration in monday’s storage.instance API. We do not operate an application backend database, do not sell personal data, and do not run third-party analytics in the MVP. We do not request account:read (seat-count gating is deferred). Optional AI features call monday’s own run_prompt GraphQL API (the monday AI gateway) — there is no third-party AI provider and no Inflexion backend; we do not store prompts or AI responses.

2. What the App does

The App displays aggregated KPI values from boards you attach to a monday.com dashboard (sums, averages, counts, filters, formula-column display values, etc.). Optional features can use monday AI to suggest a KPI definition from a plain-language description, or to explain a configured KPI.

3. Data we process

3.1 Data processed inside monday.com (not stored by us on our servers)

When you use the App, monday.com provides a session in the dashboard iframe. Using that session, the App may read:

  • Board metadata (ids, names, column definitions)
  • Item and column values needed for configured KPIs (numbers, status labels, dates, formula display values, mirror values)
  • Dashboard / theme context from the monday SDK
  • Subscription / plan signals only if monetization entitlements are enabled (app_subscription in app context — no account:read)

This data is processed in the browser to compute KPI tiles. We do not transmit board contents to a server we operate.

3.2 Configuration data

KPI tile settings are saved with monday.storage.instance (monday-hosted, per widget instance). We do not host a separate config database.

3.3 Personal data

The App is not designed to collect names, emails, or other end-user PII beyond what monday already shows in board cells you choose to aggregate. We do not maintain user profiles. Support email you send to support@inflexion.pl is processed only to respond to your request.

3.4 Optional monday AI features

When you use optional AI features, the App calls monday’s run_prompt GraphQL API (monday AI gateway) from the widget session. Depending on the feature, the prompt may include:

  • Plain-language KPI builder: your typed description plus the board’s column metadata (column ids, titles, types). Item / cell values are not sent for this feature.
  • Explain this KPI: the KPI definition plus its aggregated computed numbers (not raw board item dumps).

Processing happens within monday.com under your monday.com customer agreement. Usage is billed against the customer’s monday AI credits. Inflexion does not send this data to any third-party AI provider, does not operate an AI backend, and does not store prompts or AI responses. AI may be unavailable (for example trial plans, no credits, or an admin-disabled gateway); manual KPI configuration always works.

3.5 Analytics and cookies

MVP: no third-party analytics SDKs, no advertising cookies, no tracking pixels shipped by us.

5. Retention

  • Board data: not retained by us outside the live session / in-memory cache in the iframe.
  • Instance config: retained by monday instance storage until you remove the widget / clear storage / per monday platform rules (may reset on major app version bumps).
  • AI prompts and responses: not stored by Inflexion; any retention by monday.com follows monday’s platform terms.
  • Support emails: retained as needed to handle the request, then deleted or minimized.

We do not sell personal data. For App runtime data (board reads, instance config, and optional monday AI prompts/responses), the only subprocessor / platform is monday.com. Data stays within monday.com’s platform APIs and your browser session, except:
