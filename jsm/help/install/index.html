Install

From Atlassian Marketplace

  1. Site admin opens the Marketplace listing.
  2. Select the Jira / JSM Cloud site → Install.
  3. Review requested scopes and approve.
  4. Confirm the App appears under Apps on the site and open the Email reply dedupe admin page.
  5. Leave Enable auto-merge OFF and keep env dry-run as shipped until you finish Configuration.

Cloud Marketplace apps must match the parent product user/agent tier (Purchase & licensing FAQ). Trial length is 30 days for Marketplace apps.

From Forge CLI (developer)

High level:

cd atlassian/jsm-email-dedupe
npm install
forge login
forge register   # once
forge deploy -e development
forge install    # select Jira + site

Production deploy is a separate, explicit step (forge deploy -e production + prod install).

After install

  1. Ensure the service project has an email / mail handler channel.
  2. Create a disposable test project or use marked test tickets.
  3. Run with dry-run first (toggle OFF + env kill switch); check Forge logs (forge logs) for detection lines.
  4. Only then allow live: set env kill switch off, redeploy, and have a Jira admin enable Enable auto-merge.
